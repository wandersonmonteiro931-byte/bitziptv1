WMCPLAYER V113 - BAT CORRIGIDO PARA PUBLICAR FUNCOES SEM REENVIAR SECRETS

BASE USADA
- WMCPLAYER_V112_CORRECAO_SQL_TEXTO_UUID_INDICACOES_PACOTE_COMPLETO.zip

O QUE ACONTECEU
O BAT anterior parou porque nao encontrou o arquivo local SECRETS_SUPABASE_PIX.env.
Ele criou um modelo vazio e pediu todas as credenciais novamente.
Isso nao era necessario para esta atualizacao, porque os secrets do PIX ja ficam salvos no Supabase.

CORRECAO
- O BAT nao cria mais arquivo de secrets nesta atualizacao.
- O BAT nao reenvia, altera ou apaga secrets do Supabase.
- Reutiliza a sessao e o token fixo ja salvo na CLI.
- Publica somente as funcoes alteradas pelas indicacoes:
  1. admin-create-user
  2. admin-manage-user
  3. pix-efi

COMO USAR
1. Execute primeiro o SQL V112 no SQL Editor, caso ainda nao tenha concluido.
2. Depois execute ATUALIZAR_FUNCOES_INDICACOES_V113.bat.
3. Tambem pode executar CONFIGURAR_PIX_E_FUNCOES_SUPABASE.bat, pois ele foi substituido pela mesma versao corrigida.

IMPORTANTE
- Nao preencha nem envie secrets novamente para esta atualizacao.
- O arquivo vazio SECRETS_SUPABASE_PIX.env criado na tentativa anterior pode ser apagado do seu computador.
- Nenhum secret real foi incluido neste pacote.

SQL
- Use o SQL V112 ja presente no pacote.

SITE
- Nenhuma mudanca visual foi feita na V113. Se o site V111/V112 ja foi publicado, nao precisa publicar de novo.
